### 👨‍💻 About Me

I'm a self-taught developer who likes taking things apart to see how they work — then rebuilding them for the browser. My projects range from **porting a 1993 C game engine to WebAssembly** to **retro photo editors**, **3D physics dice rollers**, and **tools that help keep people connected to a free internet**.

- 🕹️ Currently deep in **game engines, emulation, and WebAssembly**
- 🌐 Building tools for **internet freedom** — [Freedom-V2Ray](https://github.com/MahanKenway/Freedom-V2Ray) helps people in Iran get free, uncensored access
- 🤖 Exploring **AI in game development**
- 🛡️ **Network+** certified, always learning more about security & infrastructure
- 🎮 Gaming is basically my second language
